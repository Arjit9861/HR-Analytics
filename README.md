# HR-Analytics
📊 HR Analytics – Power BI Dashboard
📌 Project Overview

This is a self-made HR Analytics project developed using Microsoft Power BI to analyze employee attrition, workforce demographics, and key HR metrics.

The dashboard provides an interactive view of employee data and helps HR teams understand attrition patterns and identify areas that may require targeted retention strategies.

🎯 Project Objective

The main objectives of this project are:

Analyze employee attrition across different departments.
Calculate and visualize key HR metrics.
Understand employee demographics.
Compare attrition across different employee categories.
Identify departments or groups with higher attrition.
Provide an interactive dashboard for HR decision-making.
🛠️ Tools & Technologies
Power BI
Power Query
DAX
Microsoft Excel
Data Cleaning & Transformation
Data Visualization
📈 Key KPIs

The dashboard includes important HR metrics such as:

Total Employees
Total Attrition
Attrition Rate
Average Employee Age
Male vs Female Employees
Department-wise Attrition
Job Role-wise Attrition
Employee Demographics
📊 Dashboard Features
1. HR Overview

Provides a high-level overview of the organization's workforce and attrition.

2. Attrition Analysis

Analyzes employee attrition across departments, job roles, and other employee categories.

3. Demographic Analysis

Provides insights into employee distribution based on factors such as gender and age.

4. Interactive Filters

Users can interact with the dashboard using filters and slicers to analyze specific departments or employee groups.
